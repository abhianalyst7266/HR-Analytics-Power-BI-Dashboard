**HR Analytics Dashboard using Power BI**
**Project Overview**
This project presents an interactive HR Analytics Dashboard developed using Microsoft Power BI. The dashboard helps analyze employee demographics, employee attrition, salary distribution, job satisfaction, experience, and department-wise employee statistics.
The objective is to transform HR data into meaningful insights that can support data-driven human resource management decisions.
**Dashboard Preview**

: Key Performance Indicators (KPIs)
: Total Employees: 1.48K
: Attrition Count: 241
: Attrition Rate: 16.28%
: Average Age: 36.94
: Average Experience: 11.28 years

**Dashboard Features**
_The dashboard includes the following visualizations:_
: Attrition by Department
: Attrition by Salary Slab
: Job Role and Satisfaction Analysis
: Age Group Distribution
: Attrition by Gender
: Attrition by Experience
: Department-wise Employee Count
: Department-wise Education Analysis

**Tools and Technologies**
: Microsoft Power BI
: Power Query
: DAX (Data Analysis Expressions)
: Data Visualization
: Data Cleaning and Transformation

**Key Insights**
: The dashboard shows 241 employee attritions.
: The overall attrition rate is 16.28%.
: The average employee age is approximately 37 years.
: The average employee experience is approximately 11.28 years.
: Employee attrition can be explored across departments, salary slabs, gender, and experience levels.
: Department-wise employee distribution helps identify workforce concentration.
